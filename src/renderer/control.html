TinRoof Timer

A cross-platform countdown timer for show operators. Remote control over TCP is compatible with the Irisdown Countdown Timer 2.0 protocol, so it works with the Bitfocus Companion module “Irisdown: Countdown Timer” as well as the dedicated TinRoof Timer module.
